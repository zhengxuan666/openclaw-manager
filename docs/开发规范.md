# OpenClaw Manager 开发规范

本文档用于统一本项目的日常开发流程与协作方式。

## 1. 分支规范

- `main`：稳定分支，仅合并已验证的改动
- `feature/<name>`：功能开发分支
- `fix/<name>`：缺陷修复分支
- `chore/<name>`：工程化或文档类改动

示例：`feature/ai-provider-settings`

## 2. 提交信息规范

建议使用 Conventional Commits：

- `feat:` 新功能
- `fix:` 缺陷修复
- `docs:` 文档更新
- `refactor:` 重构（不改变功能）
- `chore:` 构建、依赖、脚本等杂项

示例：

```text
feat: 增加飞书渠道配置表单校验
fix: 修复服务重启后状态未刷新问题
docs: 补充初始化与开发规范文档
```

## 3. 开发流程

1. 从 `main` 拉取最新代码
2. 创建功能分支进行开发
3. 本地运行并自测
4. 提交代码并发起合并请求
5. 通过评审后合并到 `main`

## 4. 本地开发命令

> ⚠️ **当前主要开发和部署场景为 Web 模式。** 请优先使用 Web 模式相关命令。

### Web 模式（主要）

```bash
# 安装依赖
npm install

# 前端构建（类型检查 + 打包）
npm run build

# Rust 后端构建
cd src-tauri && cargo build

# 一体化构建（前端 + 后端）
npm run web:build

# 启动 Web 服务器
bash scripts/1panel_web_start.sh
```

### Tauri 桌面模式

```bash
# 启动开发模式（热重载）
npm run tauri:dev

# 构建发布版本
npm run tauri:build
```

## 5. Web 模式开发注意事项（⚠️ 必读）

### 5.1 双入口命令注册

**新增 Rust 命令时，必须同时在两处注册：**

1. `src-tauri/src/main.rs` — `tauri::generate_handler![...]`（Tauri 桌面模式）
2. `src-tauri/src/web_server.rs` — `dispatch_command()` 的 match 分支（Web 模式）

只在 `main.rs` 注册会导致 Web 模式报 **"未知命令: xxx"** 错误。

### 5.2 前端 invoke 机制

前端统一使用 `src/lib/invoke.ts` 的 `invokeCommand<T>(cmd, args)`：

- **Tauri 模式**：检测到 `__TAURI_INTERNALS__` → 直接调用 `tauriInvoke()`
- **Web 模式**：通过 `fetch('/api/invoke', {cmd, args})` 发 HTTP 请求

两种模式下前端代码完全一致，差异仅在后端分发层。

### 5.3 编译验证

**每次变更后，必须同时验证前端和 Rust 编译：**

```bash
# 前端编译（检查 TypeScript 类型 + Vite 打包）
npm run build

# Rust 编译（同时编译 Tauri 桌面和 Web 两个 bin）
cd src-tauri && cargo build
```

仅执行 `npm run build` 不会检查 `web_server.rs` 中的 Rust 代码。

### 5.4 Web 模式特有的参数解析

`web_server.rs` 中的 `dispatch_command` 需要手动从 `args: &Value` 中解析参数：

- 使用 `require_string(args, &["camelCase", "snake_case"], "label")` 支持两种命名风格
- 使用 `read_arg(args, &["key"]).cloned()` 读取复杂对象
- Tauri 模式由框架自动反序列化参数，Web 模式需要手动处理

## 6. 代码风格建议

- 保持函数职责单一，避免过长函数
- 变量与函数命名语义清晰
- 优先复用已有组件与工具函数
- 改动尽量最小化，避免无关重构

## 7. 合并前检查清单

- [ ] 功能按预期工作
- [ ] **`npm run build` 前端编译通过**
- [ ] **`cd src-tauri && cargo build` Rust 编译通过**（含 web-server）
- [ ] **新增的 Rust 命令已同时在 `main.rs` 和 `web_server.rs` 中注册**
- [ ] 无明显控制台报错
- [ ] Web 模式下关键路径已手动验证
- [ ] 文档已同步更新（如有必要）
